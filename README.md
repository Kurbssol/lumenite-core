# Lumenite (LMT)

Lumenite is a Proof-of-Work cryptocurrency designed around accessible CPU and GPU mining.

## Mainnet

Lumenite Mainnet launched September 3, 2026.

| Specification | Value |
|---|---|
| Ticker | LMT |
| Consensus | Proof of Work |

| Block Time | 150 seconds |
| Block Reward | 50 LMT |
| Halving Interval | 840,000 blocks |
| Maximum Supply | ~84,000,000 LMT |
| Difficulty Adjustment | LWMA-45 |
| Coinbase Maturity | 100 blocks |
| Premine | None |
| Developer Reward | None |

## HomeScrypt v1.2

Lumenite uses HomeScrypt v1.2, a custom Proof-of-Work algorithm designed for CPU and GPU mining.

HomeScrypt is not standard Litecoin Scrypt.

Mining support includes:

- CPU
- NVIDIA CUDA
- AMD / OpenCL
- Windows
- Linux
- HiveOS
